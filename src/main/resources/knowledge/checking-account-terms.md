# Everyday Checking terms

Acme Bank is a fictional bank. These terms exist only for this demo.

## Opening an account

Everyday Checking can be opened with any amount, including zero. An account holder must be at least 18 years old.

## Available balance

The available balance is the posted balance. Pending card authorizations are not shown in this demo, so the balance
the assistant reports is the posted balance.

## Currency

Each account holds exactly one currency, set when it is opened. Transfers are only possible between accounts that hold
the same currency; the bank does not convert currencies between accounts.

## Closing an account

An account can be closed at any time once its balance is zero. There is no closing fee.
